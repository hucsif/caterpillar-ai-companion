# StackChan 两套表情系统运行逻辑对比

## 一、小黄脸系统（Emoji/GIF，已删除）

### 数据流

```
网关 llm 消息 / 应用状态机
        │
        ▼
Display::SetEmotion(const char* emotion)
        │
        ├── emotion 在 EmojiCollection 中？
        │   ├── 是 → 取 PNG/GIF 图片
        │   │        ├── GIF → LvglGif 逐帧播放
        │   │        └── PNG → 直接显示
        │   └── 否 → font_awesome_get_utf8() 查图标字符
        │             └── emoji_label_ 显示图标字符
        │
        ▼
emoji_image_（单个 lv_img 对象）或 emoji_label_（lv_label）
```

### 渲染对象（LVGL 树）

```
lv_screen_active()
  ├── container_          (全屏背景)
  ├── top_bar_            (顶部栏: WiFi/电池/静音图标)
  ├── status_bar_         (状态栏: 时间/录音图标/通知文字)
  ├── emoji_box_          (居中容器) ← 删除
  │   ├── emoji_label_    (大图标字符, 如 🎤) ← 删除
  │   └── emoji_image_    (PNG/GIF 图片) ← 删除
  ├── preview_image_      (相机预览)
  ├── bottom_bar_         (底部栏: 聊天文字/MCP结果)
  └── low_battery_popup_  (低电量弹窗)
```

### 核心类

| 类 | 文件 | 作用 |
|---|---|---|
| `Display` | `display/display.h` | 抽象基类，定义 `SetEmotion()` 虚接口 |
| `LcdDisplay` | `display/lcd_display.h/cc` | 继承 Display，创建 LVGL UI 树，实现表情逻辑 |
| `EmojiCollection` | `display/lvgl_display/emoji_collection.h/cc` | emoji 名→图片映射表 |
| `LvglGif` | `display/lvgl_display/gif/lvgl_gif.h/cc` | GIF 解码和帧播放 |
| `gifdec` | `display/lvgl_display/gif/gifdec.c/h` | 底层 GIF 解码器 |
| `LvglTheme` | `display/lvgl_display/lvgl_theme.h/cc` | 主题（持有 emoji_collection 指针） |
| `Assets` | `assets.cc` | 从固件分区加载 emoji 集合到主题 |

### 表情名称→数据映射（常量映射表）

emotion 字符串如 `"neutral"`、`"happy"` 等 21 个固定值，通过 `EmojiCollection` 映射到 LVGL 图片描述符。

## 二、矢量表情系统（StackChan Avatar，当前使用）

### 数据流

```
网关 llm 消息                         MCP set_avatar 工具
     │                                      │
     ▼                                      ▼
board.OnEmotionChanged()            SetAvatarExpression()
     │                                      │
     ▼                                      ▼
MapEmotionToAvatar()    emotion字符串 → Emotion枚举
     │
     ▼
Avatar::setEmotion(Emotion)
     │
     ├── leftEye.setEmotion()
     ├── rightEye.setEmotion()
     ├── mouth.setEmotion()
     ├── speechBubble.setEmotion()
     └── 所有 Decorator.setEmotion()
              │
              ▼
        每帧更新定时器 (30ms/33fps)
              │
         ├── 修饰器更新 (Blink→眼皮, Breath→浮动, Speaking→嘴巴)
         ├── Avatar::update() → 所有 Element/Derocrator 重绘
         └── BringUIBarsToFront() (每300ms)
```

### 渲染对象（LVGL 树）

```
lv_screen_active()
  ├── container_          (全屏背景, 从 SpiLcdDisplay.SetupUI)
  ├── top_bar_            (顶部栏: WiFi/电池/静音)  ← 保留
  ├── status_bar_         (状态栏: 录音图标/通知)    ← 保留
  ├── preview_image_      (相机预览)                  ← 保留
  ├── bottom_bar_         (聊天文字/MCP结果)          ← 保留
  ├── low_battery_popup_  (低电量)                    ← 保留
  │
  └── [DefaultAvatar 面板]  ← 矢量表情面板
        ├── 背景 (全屏黑色)
        ├── 左眼 (lvgl Container + 圆形 + 眼皮矩形)
        ├── 右眼 (同上)
        ├── 嘴巴 (lvgl Container + 弧形)
        └── 气泡 (lvgl Container + 箭头图片 + 文字标签)
```

### 图层 Z 序（从下到上）

```
(最底) DefaultAvatar 面板 → container_ → top_bar_ → status_bar_ → bottom_bar_ (最顶)
                                ↑
                    BringUIBarsToFront() 每300ms确保在前
```

### 核心类（全部在 `avatar/` 目录下）

#### 框架层 `avatar/framework/`

| 类/文件 | 作用 |
|---------|------|
| `Emotion` 枚举 | Neutral/Happy/Angry/Sad/Doubt/Sleepy |
| `Element` | 基类：位置、旋转、可见性、emotion、`_update()` |
| `Feature` | 继承 Element：增加 weight(0-100) 和 size(-100-100)，眼睛/嘴巴的基类 |
| `SpeechBubble` | 继承 Element：setSpeech/clearSpeech/setTextFont |
| `KeyElements_t` | 持有 leftEye/rightEye/mouth/speechBubble 四个指针 |
| `Avatar` | 基类：管理 Elements + Decorators 池，`setEmotion()` 广播到所有子对象 |
| `Decorator` | 基类：继承 Poolable + Element，装饰器接口 |

#### 皮肤层 `avatar/skins/`

| 类/文件 | 作用 |
|---------|------|
| `DefaultAvatar` | 实现 Avatar：创建全屏面板，初始化眼睛/嘴巴/气泡 |
| `DefaultEyes` | 白色圆形眼眶 + 黑色矩形眼皮，weight 控制眼皮上下滑动 |
| `DefaultMouth` | 弧形嘴巴，weight 控制开合程度 |
| `DefaultSpeechBubble` | 圆角矩形气泡 + 箭头图片 + 滚动文字 |

#### 装饰器层 `avatar/decorators/`

| 类 | 效果 |
|----|------|
| `HeartDecorator` | 爱心飘动（开心时） |
| `AngryDecorator` | 生气的青筋标记 |
| `SweatDecorator` | 汗滴动画（尴尬/焦虑时） |
| `ShyDecorator` | 脸颊红晕（害羞时） |
| `DizzyDecorator` | 旋转星星（眩晕时） |

#### 修饰器层 `avatar/modifiers/`

| 类 | 效果 |
|----|------|
| `BlinkModifier` | 眼睛开合状态机，每4秒眨眼一次 |
| `BreathModifier` | 眼睛和嘴巴正弦波上下浮动 |
| `SpeakingModifier` | 嘴巴随机开合模拟说话 |
| `IdleExpressionModifier` | 随机微表情（眼神游移、嘴巴歪一下等） |
| `TimedEmotionModifier` | 定时切换表情（N毫秒后恢复） |
| `TimedSpeechModifier` | 定时显示/隐藏气泡文字 |

#### 动画层 `avatar/animation/`

| 类 | 作用 |
|----|------|
| `FeatureKeyframe` | 关键帧：眼睛/嘴巴的位置/旋转/weight/size |
| `ServoKeyframe` | 舵机关键帧（已排除，栈中不用） |
| `Keyframe` | 组合 FeatureKeyframe + ServoKeyframe + 持续时间 |
| `Timeline` | 关键帧序列播放器（start/stop/pause/resume/loop） |

#### 工具层 `avatar/utils/`

| 类/函数 | 作用 |
|---------|------|
| `ObjectPool<T>` | 对象池：管理 Avatar 的 Decorator 和 Modifier 生命周期 |
| `Random` | 单例随机数生成器 |
| `avatar_millis()` | 替代 `GetHAL().millis()`，返回 `esp_timer_get_time()/1000` |

#### 接口层

| 类 | 作用 |
|----|------|
| `Modifiable` | 简化版接口：暴露 `avatar()` 和 `hasAvatar()` |
| `Modifier` | 基类：`_update(Modifiable&)`，每帧被 avatar 定时器调用 |

### 情绪映射表

```
"neutral"               → Emotion::Neutral
"happy"/"laughing"/
  "funny"/"loving"      → Emotion::Happy
"angry"                 → Emotion::Angry
"sad"/"crying"/"sleepy" → Emotion::Sad
"thinking"/"confused"   → Emotion::Doubt
其他                    → Emotion::Neutral
```

### 初始化时序

```
StackChanBoard 构造
  → InitializeVectorAvatarDeferred()
    → 创建 500ms 定时器
    → 定时器回调检查 lv_screen_active() 是否有子对象（SetupUI 完成信号）
    → TryCreateVectorAvatar()
      → new DefaultAvatar() + init()
      → 创建 BlinkModifier + BreathModifier
      → 启动 30ms 更新定时器
```

### 更新循环（每 30ms）

```
VectorAvatarUpdateCb
  → BringUIBarsToFront() (每10帧)
  → avatar_modifier_pool_.forEach → Modifier::_update()
  → vector_avatar_->update()
    → _key_elements.forEach → Element::_update()
    → _decorator_pool.forEach → Decorator::_update()
```

## 三、两系统关键差异

| 维度 | 小黄脸 | 矢量表情 |
|------|--------|---------|
| 表情表示 | 静态图片/动画文件 | 程序化 LVGL 对象状态 |
| 表情数据量 | 每表情一个文件 (KB~MB) | 代码 + 少量装饰器图片素材 |
| 动画方式 | GIF 帧解码器 | 修饰器状态机实时计算 |
| 表情切换 | 换一张图片 | 修改 Element 状态，平滑过渡 |
| 可扩展性 | 需要预制作图片 | 新增装饰器/修饰器代码即可 |
| 内存占用 | GIF 帧缓冲区 | LVGL 对象开销（轻量） |
| 表情丰富度 | 固定 21 种 | 组合 eyes×mouth×decorators×modifiers→∞ |
| 接口 | Display::SetEmotion(string) | Avatar::setEmotion(enum) + Modifiable |

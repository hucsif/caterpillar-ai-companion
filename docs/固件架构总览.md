# stackchan-mcp 固件完整运行流程

## 一、启动流程

```
上电
  │
  ▼
bootloader (ESP-ROM)
  │
  ▼
app_main() → Application::Initialize() → Application::Run()
```

### 构造函数阶段

```
StackChanBoard::StackChanBoard()
  ├── InitializePowerSaveTimer()      // 空闲省电定时器
  ├── InitializeI2c()                 // 内部 I2C 总线 (PMIC/触摸/IO扩展等)
  ├── InitializePortAI2c()            // 外部 I2C 总线 (Grove 接口)
  ├── InitializeAxp2101()             // 电源管理芯片
  ├── InitializeAw9523()              // IO 扩展芯片
  ├── InitializeSpi()                 // SPI 总线
  ├── InitializeIli9342Display()      // 创建 SpiLcdDisplay → 初始化 LVGL
  ├── InitializeCamera()              // 摄像头 (可选)
  ├── InitializeFt6336TouchPad()      // 触摸屏
  ├── InitializeIOExpander()          // PY32 LED 扩展
  ├── InitializeServo()               // SCS0009 舵机 (UART)
  ├── InitializeTouchSettings()       // 触摸传感器设置
  ├── InitializeSi12tTouch()          // 头部触摸传感器
  ├── I2cDetect()                     // I2C 设备扫描 (调试用)
  ├── InitializeVectorAvatarDeferred() // 延迟创建矢量表情
  ├── InitializeMouthSequenceTask()   // 嘴巴序列任务
  ├── caterpillar_http_init()         // MQTT 广播 (已禁用)
  ├── caterpillar_radar_init()        // 毫米波雷达 (已禁用)
  └── RegisterMcpTools()             // 注册所有 MCP 工具
```

### Application::Initialize()

```
Application::Initialize()
  ├── board.GetDisplay()->SetupUI()   // 创建 LVGL UI 树
  ├── audio_service_.Initialize()     // 音频编解码器初始化 (ES7210+AW88298)
  ├── audio_service_.Start()          // 启动 3 个音频任务
  ├── 注册音频回调:
  │     on_send_queue_available → MAIN_EVENT_SEND_AUDIO
  │     on_wake_word_detected   → MAIN_EVENT_WAKE_WORD_DETECTED
  │     on_vad_change           → MAIN_EVENT_VAD_CHANGE
  ├── 注册状态变更回调 → MAIN_EVENT_STATE_CHANGED
  ├── 启动 1 秒定时器 (更新状态栏)
  ├── McpServer 添加通用工具 + 用户工具
  ├── board.SetNetworkEventCallback() // WiFi 事件处理
  └── board.StartNetwork()            // 启动 WiFi 异步连接
```

### 网络连接后

```
MAIN_EVENT_NETWORK_CONNECTED
  → 状态变为 Activating
  → ActivationTask (后台任务):
      ├── CheckAssetsVersion()    // 检查资源更新
      ├── CheckNewVersion()       // 检查固件更新
      └── InitializeProtocol()    // 建立 WebSocket
            ├── 创建 WebsocketProtocol
            ├── 注册 OnIncomingAudio 回调
            ├── 注册 OnIncomingJson 回调
            └── Start() → 发送 hello → 等待服务端 hello
  → 状态变为 Idle
  → 播放成功提示音
```

## 二、主事件循环

```cpp
Application::Run() {
    while (true) {
        bits = xEventGroupWaitBits(ALL_EVENTS);  // 阻塞等待

        if (MAIN_EVENT_SEND_AUDIO)          // 发音频到网关
        if (MAIN_EVENT_WAKE_WORD_DETECTED)  // 唤醒词
        if (MAIN_EVENT_VAD_CHANGE)           // VAD 状态变化
        if (MAIN_EVENT_CLOCK_TICK)           // 1 秒心跳
        if (MAIN_EVENT_ERROR)                // 网络错误告警
        if (MAIN_EVENT_NETWORK_CONNECTED)    // 网络连接
        if (MAIN_EVENT_NETWORK_DISCONNECTED) // 网络断开
        if (MAIN_EVENT_TOGGLE_CHAT)          // 按键切换对话
        if (MAIN_EVENT_START_LISTENING)      // 开始拾音
        if (MAIN_EVENT_STOP_LISTENING)       // 停止拾音
        if (MAIN_EVENT_ACTIVATION_DONE)      // 激活完成
        if (MAIN_EVENT_STATE_CHANGED)        // 状态变更
        if (MAIN_EVENT_SCHEDULE)             // 延时任务队列
    }
}
```

## 三、语音对话流程 (ASR→LLM→TTS)

详见 [voice-pipeline.md](voice-pipeline.md)

简化为四个状态流转：

```
Idle ──唤醒词/按键──▶ Connecting ──▶ Listening ──VAD静音──▶ Idle
                                                        网关 TTS
                                                           │
                                                           ▼
                      Idle ◀──tts.stop── Speaking ◀──tts.start
```

### 音频任务模型

| 任务 | 优先级 | 核心 | 职责 |
|------|--------|------|------|
| 主事件循环 | 10 | any | 状态机、发音频、UI |
| `audio_input` | 8 | 0 | 每 10ms 读麦克风 |
| `audio_output` | 4 | any | 写 PCM 到喇叭 |
| `opus_codec` | 2 | any | 编解码 Opus |

### MCP 消息流

```
WebSocket 文本帧 {"type":"mcp","payload":{...}}
  → Application::OnIncomingJson
  → McpServer::ParseMessage(payload)
  → JSON-RPC 2.0 解析
  → tools/call → DoToolCall()
  → 遍历工具参数，从 JSON 提取值
  → 调用工具回调函数
  → 返回结果 JSON
```

## 六、矢量表情系统

源码目录：`firmware/main/avatar/`

### 框架层 `framework/`

| 类 | 职责 |
|----|------|
| `Emotion` 枚举 | Neutral/Happy/Angry/Sad/Doubt/Sleepy |
| `Element` | 基类: 位置/旋转/可见性/emotion/`_update()` |
| `Feature` | 继承 Element: weight(0-100) + size(-100~100) |
| `SpeechBubble` | 继承 Element: 气泡文字 |
| `KeyElements_t` | 持有 4 个核心元素指针 |
| `Avatar` | 基类: 管理 Elements+Decorators 池 |
| `Decorator` | 装饰器基类 |

### 皮肤层 `skins/`

| 类 | 绘制方式 |
|----|----------|
| `DefaultAvatar` | 全屏黑色面板，组装 eyes+mouth+bubble |
| `DefaultEyes` | 白色圆形 + 黑色矩形眼皮，weight 控制眼皮上下 |
| `DefaultMouth` | 弧形嘴巴，weight 控制开合 |
| `DefaultSpeechBubble` | 圆角矩形 + 箭头 + 滚动文字 |

### 修饰器 `modifiers/`

| 类 | 效果 |
|----|------|
| `BlinkModifier` | 每 4 秒眨眼 |
| `BreathModifier` | 正弦波呼吸浮动 |
| `SpeakingModifier` | 嘴巴随机开合 |
| `IdleExpressionModifier` | 随机微表情 |
| `TimedEmotionModifier` | 定时切换表情 |
| `TimedSpeechModifier` | 定时气泡文字 |

### 初始化与运行

```
构造函数 → InitializeVectorAvatarDeferred()
  → 创建 500ms 定时器轮询
  → SetupUI 完成后 lv_screen_active() 有子对象
  → TryCreateVectorAvatar()
    → new DefaultAvatar() + init()
    → 创建 BlinkModifier + BreathModifier
    → 隐藏 emoji (HideEmojiDisplay)
    → 启动 30ms 更新定时器

每 30ms:
  VectorAvatarUpdateCb
    → BringUIBarsToFront() (每 10 帧)
    → Modifier::_update() (blink + breath)
    → Avatar::update() (重绘所有元素)
```
